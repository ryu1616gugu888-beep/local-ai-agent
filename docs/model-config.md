# モデル設定

`DEFAULT_MODEL` と `CONTEXT_WINDOW` は `core.py` の冒頭で設定されている。新しいモデルを評価・変更するときに参照する。

## 検閲解除モデルの使用は意図的

使用しているモデルはOllamaのabliterated（検閲解除）コミュニティビルド、例: `huihui_ai/gemma-4-abliterated:26b`。これはユーザーの「無制限のローカルモデルが欲しい」という明示的な要件によるもの — 頼まれていないのに標準の安全アラインメント済みモデルへ「修正」しないこと。

`CONTEXT_WINDOW` は、このマシンのユニファイドメモリ予算でKVキャッシュメモリを圧迫しすぎないよう、モデルの理論上の最大値より意図的に低く抑えられている。

## ハードウェア制約とモデル選定

このマシン（16インチMacBook Pro、M4、24GB ユニファイドメモリ）は大規模ローカルモデルにとってメモリ制約がある：密な（dense）約27Bモデルは、部分的にCPUオフロードされるため、同程度のサイズのMoEモデル（総パラメータ約26B/アクティブ約4B）と比べて、同一タスクでの実測が約3倍遅かった。このサイズクラスで新しいモデルを評価する際は、denseアーキテクチャよりMoEアーキテクチャを優先し、新しいモデル選択は `ollama ps` で（ロードされるかどうかだけでなく）CPU/GPUの分割状況を確認して健全性チェックすること。
